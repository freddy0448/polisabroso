# Mission: Manage Polisabroso with engineering skills

## Why

The user currently manages Polisabroso alone. Learn to use the engineering
skills to organize work and decide when a task is ready to hand to an agent.

## Success looks like

- Explain the difference between repository setup and issue triage.
- Choose an appropriate triage state for an issue and explain why.
- Describe a task clearly enough for an agent to implement and verify it.

## Constraints

- One maintainer for now; use examples from Polisabroso.

## Out of scope

No additional exclusions established yet.
