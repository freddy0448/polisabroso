Decide what happens next.

You manage Polisabroso yourself. For this lesson, your goal is to decide whether an issue needs more information or is ready to hand to an agent.

Setup records the conventions

The setup skill records where issues live, which labels to use, and where domain documents belong. Your repository now points to GitHub Issues and uses five triage states. See the tracker configuration and label mapping.

Triage evaluates one piece of work

Triage means reviewing an issue and deciding its next step. Even when you wrote the issue yourself, it can still need details before you or an agent can act on it.

The installed triage skill uses one category, such as bug or enhancement, and one state. bug describes the kind of work; needs-info describes what must happen next. These rules come from the triage skill's Roles section.

A hypothetical login issue

“Login doesn't work” leaves the reproduction steps and observed behavior unclear. A reasonable recommendation is bug plus needs-info.

After you supply the missing details, the skill returns the issue to needs-triage for evaluation. Once the problem is verified and fully specified, it may become ready-for-agent with an implementation brief.

ready-for-agent means the issue is prepared for implementation. It does not mean implementation has started or finished. The skill's Apply the outcome section calls for an agent brief at that point.

Try it before reading the feedback

You write “Improve registration.” The issue gives no description of the desired behavior. Which state best fits this missing information? Choose an answer, then open it.

A. Use ready-for-agent

Not yet. An agent would have to invent the desired improvement. Specify the expected behavior first.

B. Use needs-info

Correct. The missing information is the desired behavior. As the solo maintainer, you can supply it yourself.

C. Use ready-for-human

This state is for work requiring human implementation. It does not resolve an unclear request.

Apply it to your next issue

Write what happens now, what should happen, and how you will check the result. Then ask $triage Review issue #<number>. This is a suggested prompt, not an action taken by this lesson.
