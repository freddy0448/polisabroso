Setup and triage

Term Meaning in this workflow
Issue A recorded bug, requested improvement, or task.
Setup Records repository conventions for the engineering skills.
Triage Evaluates an issue and decides its next step.
Category The kind of work: bug or enhancement.
State The issue's current disposition, using one label below.
Agent brief A durable description of work prepared for an implementing agent.

Five states

Label Meaning
needs-triage Needs evaluation.
needs-info Waiting for information.
ready-for-agent Fully specified for an agent to implement.
ready-for-human Requires human implementation.
wontfix Will not be actioned.

These are dispositions, not a checklist to complete in sequence. After the reporter answers a needs-info request, return to evaluation.

Sources: Polisabroso label mapping and the installed triage skill.
